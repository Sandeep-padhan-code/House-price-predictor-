# 🏠 House Price Prediction using Machine Learning

A beginner-friendly Machine Learning project that predicts house prices based on features like area, number of bedrooms, bathrooms, and location.

---

# 📌 Project Overview

This project uses Machine Learning algorithms to estimate the price of houses from given input features.

The main goal of this project is to:
- Learn data preprocessing
- Understand regression models
- Train and test ML models
- Build a real-world ML application

---

# 🚀 Features

✅ Predict house prices  
✅ Data visualization  
✅ Data preprocessing  
✅ Model training and evaluation  
✅ Simple and beginner-friendly code

# 📊 Dataset

The dataset contains:

| Feature | Description |
|---|---|
| Area | Size of house |
| Bedrooms | Number of bedrooms |
| Bathrooms | Number of bathrooms |
| Stories | Floors in the house |
| Parking | Parking spaces |
| Price | Target variable |

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/House-Price-Prediction.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd House-Price-Prediction
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

```bash
python app.py
```

Or open the Jupyter Notebook:

```bash
jupyter notebook
```
